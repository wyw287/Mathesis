# Mathesis

**对话驱动的数学教学画布。**

不是「聊天 + 数学插件」。聊天只是控制层,主角是画布 —— AI 在上面生成可交互的图、
可折叠的推导、能亲手试的反例和小测。数学里一句话讲不清的东西,一张能拖的图就清楚了。

纯前端、无后端、自带 Key(BYOK)。构建产物是一堆静态文件;你的 API Key 和全部学习
记录只待在这台浏览器的本地数据库里,不上传任何服务器。

---

## 画布上有什么

每样东西都是**一等对象**:能引用、能改、能回看,而不是聊天记录里的一段死文本。
这就是它和"让 AI 把公式写在对话里"最本质的区别。

| kind | 是什么 | 能做什么 |
|---|---|---|
| `plot2d` | 函数图像 | 显式 / 参数 / 序列 / 隐式曲线、向量场、滑块拖参数 |
| `plot3d` | 曲面 | 高度图与参数曲面,可拖动旋转 |
| `derivation` | 分步推导 | 每步标"关键 / 套定义 / 我跳过了"、可折叠理由、逐条机器核对、单步「这步不懂」 |
| `quiz` | 小测 | 当场判对错 |
| `counterexample` | 反例工作台 | 给一组条件,拖到"前提全满足而结论不成立" |
| `compare` | 并排对比 | 两个概念、两张图放在一起看,差异才看得出来 |
| `diagram` | 流程 / 逻辑图 | 坐标由系统自动排,模型只写节点和边 |
| `linear` | 线性变换 | 模型只写矩阵,几何结果全由代码算;基向量的像可以直接拖 |
| `matrix` | 矩阵 | 任意尺寸的行列、乘法过程(逐项展开的行 × 列)、转置与逆 |
| `html` | 交互内容 | Tier 2 逃生舱口,跑在 iframe 沙箱里 |

## 两条贯穿始终的原则

### 一、不冒充确定性

这是整个项目里最反复出现的一条设计约束,它出现在三个完全不同的层:

- **推导核对是三态,不是布尔。** CAS 化简不出来时如实说"化简不出来",而不是判这一步错
  (详见下一节)。
- **反例工作台的每条条件也是三态。** "连续""可导""一致收敛"这些在数值上根本没法验证 ——
  把它们和算出来的挤成同一个对勾,等于给学生一个**假的确定性**,那比不做检查更糟。
- **存储降级会明说。** IndexedDB 用不了时,顶栏直接写「存储不可用,本次内容不会被保存」,
  而不是默默降级让用户以为存上了。

### 二、每一步都能被核对

通用 AI 讲题最大的问题是:它说"这一步显然成立",学生只能信。而对自学者来说,
**"这一步到底对不对"恰恰是他没法自己验证的那件事**。

所以推导的每一步都可以额外带一个**机器可读形式**,交给 CAS(nerdamer,跑在 Web Worker 里,
超时就丢掉线程)真的算一遍:

| 情形 | 结论 |
|---|---|
| 化简后差为 0 | ✓ 机器核对通过 |
| 非零,但数值抽样处处一致 | ~ 化简不出来(弱证据) |
| 非零,且抽样点算出不一致 | ✗ **这一步是错的** |

中间那一态不能省。实测发现 nerdamer 认不出 `sin(2x) = 2sin(x)cos(x)` ——
把"非零"直接当成"错了",会冤枉正确的步骤。**冤枉一个正确的步骤,比漏报一个错误的步骤
伤害大得多。**

而第三行是这套东西最有价值的产出:它让系统第一次能**指出模型讲错了**,而不是让学生去信任它。

## 跑起来

需要 Node 18+。

```bash
npm install
npm run dev          # http://localhost:5173
```

然后点右上角「设置」填服务商、API Key、模型。走 OpenAI 兼容协议,内置 DeepSeek /
OpenAI / Moonshot / 本地 Ollama 四个预设。

设置里有一颗「测试连接」按钮:它单发一个最小请求,把失败原因**原样**带回来。
有它就不用靠反复发消息去猜,到底是 URL 错了、Key 错了,还是 CORS 拦了。

### 构建与部署

```bash
npm run build        # tsc --noEmit && vite build → dist/
```

`base` 设成了 `./`,所以 `dist/` 可以直接丢进任意静态托管(包括子路径),
也能用 `file://` 直接打开。没有后端,没有运行时依赖。

## 数据都在本地

- 全部会话、画布、交互记录存在浏览器的 **IndexedDB** 里
- **API Key 明文存在同一个库里**,不上传任何地方 —— 但也意味着别在公用电脑上填
- 图片附件放在独立的 blob 存储里,不混进会话存档
- 想清掉一切:在浏览器的站点数据里删掉这一项即可

## 几个不明显的地方

- `Enter` 发送,`Shift+Enter` 换行
- 题目截图可以直接 `Ctrl+V` 粘进输入框,也可以直接拖进去
- 推导的每一步都有「这步不懂」。那是最强的困惑信号,会**立刻**告诉模型
- 顶栏那个「上下文 12.3k」是最近一次请求发出去的输入 token 数。会话长到模型装不下时,
  请求会被直接拒;那时「清空对话」或开一个新会话(画布上的图都还在,不会丢)

## 开发

### 自检

```bash
npm run check        # 12 个脚本,636 条断言
```

**没有用测试框架。** 每一层是一个独立的 node 脚本,用 esbuild 打包后直接跑,
自带一个几十行的断言小工具。可以单独跑一层:

| 脚本 | 管什么 |
|---|---|
| `contract` | artifact 契约与校验器 —— 它的输入是**模型的输出**,不可信 |
| `client` | 对残缺的第三方接口的容错:流断在半路、发完 `[DONE]` 却不关连接…… |
| `render` | Markdown / LaTeX 渲染,含恶意输出 |
| `agent` | 完整循环:模型 → 工具 → 状态。用假 HTTP 服务器跑,断言的是**真实发出的请求体** |
| `storage` `image` | 落盘合并与降级、图片库、数据库版本升级 |
| `store` | 会话层:切换、归档、快照、图片回收 |
| `cas` `field` `scene` `matrix` `layout` | 各层纯计算 |

这些层是刻意做成**能在 node 里跑通**的,所以代码里不用 `FileReader`、不依赖 canvas、
不依赖 `localStorage` —— 凡是只在浏览器里存在的 API,都会让那一层变成不可测。

### 结构

```
src/
  kinds/<kind>/      一种 artifact 的全部:spec 解析、标题、渲染器、工具
  kinds/registry.ts  唯一认识所有 kind 的地方(显式列表 + 编译期完整性断言)
  llm/               请求、agent 循环、系统提示词、降级路径
  lib/               CAS 核对、存储、图片、几何、LaTeX 拍平
  components/        对话、画布、卡片、设置
  store/             会话与画布状态(zustand + IndexedDB)
docs/artifact-schema.md    ← 契约在这里。改行为之前先读它
```

### 加一种新 artifact

新建一个 `src/kinds/<kind>/` 目录,实现 `KindModule` —— 解析、标题、渲染器、工具
四件事放在一起(拆开的话,想搞清"这个 kind 是怎么回事"要跳四个文件)。
然后在 `kinds/registry.ts` 的列表里加一行。

类型系统会在三处拦住你漏掉的成员:注册表完整性断言、`ArtifactCard` 里的类别表、
以及按 kind 分派的分支。细节见 `docs/artifact-schema.md` §10。

## 已知边界

- **没有自动压缩对话。** 上下文满了就是满了 —— 顶栏显示用量,由你决定什么时候清空或
  开新会话。摘要会丢掉"刚才第三步"这类指代,对推导尤其危险。
- **图片输入默认关。** 默认预设是 DeepSeek,它不吃图片。换成支持视觉的模型后,
  去设置里打开「当前模型支持图片输入」。
- **公式核对的覆盖面有限。** nerdamer 化简不出来的步骤会显示"化简不出来",而不是判错。
- **没有导出和分享。** 画布不能导出成图片或 HTML,会话也不能导出。
- **单机、单浏览器。** 没有账号,也就没有多设备同步。
- 这是个**个人项目**,还在长。
